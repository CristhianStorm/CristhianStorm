## Sobre mí

Soy desarrollador de software Full Stack y estudiante de **Ingeniería Informática en Paraguay**. Me interesa convertir problemas concretos en aplicaciones claras y útiles, conectando interfaces, lógica de negocio y datos.

- Desarrollo de aplicaciones web y servicios backend.
- Trabajo con bases de datos relacionales y acceso a datos con JPA y SQL.
- Interés en automatización, arquitectura de software y mejora de sistemas existentes.
- Mi código público incluye una aplicación académica de tutorías, una API de productos y prácticas de Python, PHP y desarrollo web.

## Proyectos destacados

### 🎓 Tutorías online

Aplicación académica para conectar estudiantes y docentes y organizar el seguimiento de las sesiones.

- Registro, autenticación JWT y roles de acceso.
- Consultas, foros y archivos adjuntos.
- Informes PDF e integración con videollamadas Jitsi/JaaS.

**Java 17 · Spring Boot · Spring Security · Spring Data JPA · Oracle**

[Ver código »](https://github.com/CristhianStorm/Curso-sincronico)

### 📦 API de productos

Práctica de backend para gestionar un catálogo mediante una API REST.

- Crear, listar, consultar, actualizar y eliminar productos.
- Validar precio y stock; calcular estadísticas del catálogo.
- Persistencia con JPA y H2 en memoria.

**Java 21 · Spring Boot · JPA · H2 · Maven**

[Explorar la API »](https://github.com/CristhianStorm/java/tree/main/CrusoJava/curso_java-main/productoapi)

### 🐍 Laboratorio Python

Prácticas independientes que van de los fundamentos del lenguaje a servicios web y contenedores.

- Servicios Flask, blueprint de login y Swagger UI.
- Consultas SQL con MySQL.
- Dockerfile y Docker Compose para explorar entornos locales.

**Python · Flask · MySQL · Docker**

[Recorrer las prácticas »](https://github.com/CristhianStorm/Python)

<details>
<summary>Arquitectura y alcance técnico</summary>

En tutorías se identifican controladores, servicios, repositorios JPA y entidades; algunos controladores también acceden directamente a repositorios. En la API de productos, el controlador utiliza el repositorio directamente: existe un servicio que todavía no integra ese flujo.

Las funcionalidades se contrastaron con el código público. Los proyectos y prácticas requieren su configuración local; su presencia no implica una demo productiva ni una certificación de seguridad.
