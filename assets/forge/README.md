# CS // DIGITAL FORGE

Sistema visual original para el perfil de Cristhian Storm. Generado con SVG locales, sin fuentes, scripts ni imágenes externas. Nueve módulos, con composiciones de escritorio/móvil y temas claro/oscuro.

La arquitectura tiene movimiento suave en un único conector CSS/SVG, con una alternativa estática para prefers-reduced-motion. El contenido permanece visible sin animación. Las imágenes se insertan con picture; no se necesita CSS o JavaScript en el README.

Los módulos muestran información técnica pública; Unity/C# se marcan como interés. Hay una transcripción accesible al final del README. La arquitectura está rotulada como conceptual y se aclaran los flujos reales.

El diseño anterior está en la rama codex/backup-before-digital-forge-20261030, además de conservar sus archivos en main. Para restaurarlo, recuperar README.md de esa rama; no hace falta eliminar los nuevos recursos.
